# Personal AI Knowledge · Codex 分享版

版本：v0.2.0-share，2026-10-20。

让知识参与真实工作：调用已有知识、按用途加工资料、学习用户修正，并在确认后更新本地 Markdown。支持可选的脱敏云端发布交接与 NAS 备份流程说明。

## 安装

解压后，将整个 `personal-ai-knowledge-codex` 文件夹复制到 `~/.codex/skills/`。Windows 通常是 `C:\Users\你的用户名\.codex\skills\`。若有同名版本，先备份再更新。

也可以把 ZIP 发给 Codex，说：“请检查并安装这个 skill”。安装后在下一轮对话调用 `$personal-ai-knowledge-codex`。

## 开始使用

已有知识库：

> 使用 $personal-ai-knowledge-codex。我的本地知识库在【实际路径】，请先读说明和索引，帮助我完成【当前任务】。不要上传资料。

初次建立：

> 使用 $personal-ai-knowledge-codex，帮我在【实际路径】建立知识工作流。我希望以后做【具体任务】时，能够参考过去的【经验或资料】。

## 能力与边界

- 本地模式不需要 IMA 或 WorkBuddy。现有知识库优先沿用，不强制重建目录。
- 原文、知识、案例、规则是可选加工成果，不强制每份资料都生成四份。
- 云端目标和工具分工由使用者选择。WorkBuddy → IMA 是可选交接模式。
- skill 是工作指令，不内置 API、账号、自动同步程序或 NAS 连接。涉及外部读写仍需实际工具与授权。
- 未确认的 AI 推断不成为用户观点；资料不默认上传；课程原文不随包附送。
- 已通过 Codex 技能格式校验；本地/云端/NAS 全链路仍需在使用者真实环境中验证。

## 包含内容

仅有技能说明、五个按需引用的参考/模板文件及本说明。无个人知识库、聊天记录、客户材料、课程全文、密码或连接凭据。
